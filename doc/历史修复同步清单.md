# 历史修复同步清单

本文用于跟踪 `F:\bigsinger\zhupite.github.io\_posts\dev\duilib` 中历史修复文档与当前新版 DuiLib、DuiDesigner、demo 的同步状态。

## 当前结论

- 该同步任务尚未全部完成：DuiLib 运行时已覆盖若干关键修复，DuiDesigner 的属性保存、外部修改提示、资源定位和完整属性矩阵仍需继续核对。
- `CDuiString` 等号重载问题已通过移除 `CDuiString`、统一使用 `tstring` 解决。
- TinyXML 属性保存引号问题已核对，当前 `TiXmlAttribute::Print` 固定使用双引号输出转义后的属性值。
- `CComboUI::SelectItem` 在隐藏 Tab 页中可能失效的问题已同步到 `CComboUI::Add` 和 `CComboUI::AddAt`，新增子项后会恢复子项内部可见性。
- DuiDesigner 已恢复为当前编辑器基线；已补入 `SwitchButton` 基础创建入口，外部修改提示、资源定位、属性模板、属性保存、批量选择等历史能力仍需要在后续 DuiDesigner 同步中重新核对。
- ActiveX、WebBrowser、Flash 相关文档只保留迁移说明，不再进入新版主库。
